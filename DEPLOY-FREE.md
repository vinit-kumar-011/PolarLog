# Deploy PolarLog for free (Render + Aiven MySQL + UptimeRobot)

No credit card needed for any of these (as of Sept 2026 - check each site's current terms).

| Piece | Service | Free-tier catch |
|---|---|---|
| Flask API + frontend | Render free web service | Sleeps after 15 min without traffic; ~1 min to wake up |
| MySQL | Aiven free MySQL (1 GB) | Powers off after a period of inactivity (they email you first) |
| Keep-alive | UptimeRobot free monitor | Unofficial workaround, not guaranteed |

## 1. Database (Aiven)
1. Sign up at aiven.io -> create a **free MySQL** service.
2. When it shows "Running", copy the **Service URI** from the overview page. It looks like
   `mysql://avnadmin:PASSWORD@host:PORT/defaultdb?ssl-mode=REQUIRED`.

## 2. Push to GitHub
Unzip, push the folder to a GitHub repo. Make sure `backend/.env` is NOT committed.

## 3. Web service (Render)
1. dashboard.render.com -> **New -> Blueprint** -> pick your repo (it reads `render.yaml`).
   (Or **New -> Web Service**, plan **Free**, build `pip install -r requirements.txt`,
   start = the `startCommand` line in `render.yaml`, health check path `/healthz`.)
2. Fill in when asked / under Environment:
   - `POLARLOG_DB_URL` = the Aiven Service URI
   - `POLARLOG_ADMIN_PASSWORD` = password you want for the `admin` user
   - `POLARLOG_SECRET_KEY` = auto-generated by the blueprint (otherwise a random 64-char string)
   - `WEATHERAPI_KEY` = optional
3. Deploy. In the logs look for `[init_db] done`, then open `https://<name>.onrender.com` and log in as `admin`.
   You can delete `POLARLOG_ADMIN_PASSWORD` afterwards.

## 4. Keep it awake (optional)
uptimerobot.com -> New monitor -> HTTP(s) -> URL `https://<name>.onrender.com/healthz?db=1`,
interval 5 minutes. `?db=1` also touches the database so it doesn't look idle.
This keeps the service warm but is not an official Render feature. A free service running
24/7 uses ~730 of Render's 750 free hours per month, so it stays within the allowance.

## Limits to know
- Render free: 1 min cold starts, restarts at any time, no shell access, no disk (fine - the app stores nothing on disk).
- Render free blocks outbound SMTP ports 25/465/587, so emailed password-reset codes won't work
  there; codes are printed in the Render logs (current console mode).
- Aiven free: 1 GB, max 76 connections, no SLA, powers off when idle (turn it back on in the Aiven console).
- Optional: set `POLARLOG_DB_SSL_CA` to a downloaded Aiven CA file path to fully verify TLS.
